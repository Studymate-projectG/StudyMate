# StudyMate

StudyMate is a web app that helps female university students form study groups by course.

CS 388T - Agile Software Development, Section 7C6. Sprint 1: October 7 - 21, 2026.

## Sprint 1 features

1. Sign up and log in with a university email.
2. Create and edit the profile (major and courses).
3. Create a study group.
4. Browse the groups and filter them by course code.
5. Join a group that has a free seat (no double join, no join when full).

## Built with

HTML, CSS, JavaScript, Firebase Authentication and Cloud Firestore.
